Acerca de

Sumcoin Explorer es un explorador de blockchain de código abierto para la red Sumcoin. Permite consultar bloques, transacciones, direcciones, saldos y el estado de la red en tiempo real.

El explorador funciona con Sumcoin Core y Sumcoin Insight API. Los desarrolladores pueden utilizar las APIs REST y WebSocket para crear monederos, servicios y aplicaciones que necesiten datos indexados de la blockchain.

Consulta la documentación de la API o informa de un problema.
