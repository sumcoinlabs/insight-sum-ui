¿Qué demuestra?

Un monedero Sumcoin puede utilizar la clave privada de una dirección para crear una firma criptográfica sobre cualquier texto.

Si esta página indica que la firma es válida, demuestra que:

Quien creó la firma controlaba la clave privada de la dirección Sumcoin indicada cuando se creó la firma.

La clave privada nunca se revela.

No es un servicio de mensajería

Verificar un mensaje firmado no envía el mensaje a otra persona y no publica automáticamente nada en la blockchain.

No:

  • envía un mensaje de texto o chat
  • crea una transacción Sumcoin
  • gasta Sumcoin
  • cobra una comisión de red
  • publica el mensaje en la blockchain
  • revela la clave privada
Ejemplo

Una persona podría firmar:

Controlo esta dirección Sumcoin.
Verificación solicitada por example.com.
Fecha: 2026-09-27
Nonce: 7F42A91C

El monedero devuelve una firma criptográfica. Después puede proporcionar: 

Dirección:
SUMCOIN_ADDRESS

Mensaje:
Controlo esta dirección Sumcoin.
Verificación solicitada por example.com.
Fecha: 2026-09-27
Nonce: 7F42A91C

Firma:
BASE64_SIGNATURE

Cualquier persona puede utilizar esta página para comprobar esos tres valores sin conocer la clave privada.

¿Cómo creo un mensaje firmado?

Utiliza un monedero Sumcoin de confianza que controle la dirección. La clave privada debe permanecer dentro del monedero.

Sumcoin Core admite el comando RPC signmessage. 

sumcoin-cli signmessage \
  "YOUR_SUMCOIN_ADDRESS" \
  "Tu mensaje exacto"

Si el monedero está cifrado, puede ser necesario desbloquearlo temporalmente antes de firmar.

Nunca pegues tu clave privada en este explorador. Para verificar sólo se necesitan la dirección, el mensaje y la firma resultante.
¿Se puede guardar un mensaje firmado en la blockchain de Sumcoin?

Sí, pero es una operación independiente.

Una firma de mensaje normal permanece fuera de la blockchain. Sumcoin Core también admite salidas de datos OP_RETURN, que una aplicación puede utilizar para incluir una pequeña cantidad de datos en una transacción.

Una aplicación podría:

  1. crear un mensaje,
  2. firmarlo con una dirección Sumcoin,
  3. verificar la firma, y después
  4. almacenar un mensaje corto, la firma o un hash criptográfico en una transacción independiente.

Una vez confirmada, la blockchain proporciona un registro público permanente de que ese compromiso de datos existía.

Los datos en una blockchain son públicos y prácticamente permanentes. Nunca almacenes claves privadas, contraseñas, secretos personales ni información confidencial.
¿Qué no demuestra la verificación?

Una firma válida demuestra control de la clave privada asociada a la dirección. Por sí sola no demuestra la identidad legal de la persona.

Tampoco demuestra automáticamente cuándo se firmó el mensaje. Para demostrar control actual, incluye una fecha, el propósito de la firma y un nonce único antes de firmar.
